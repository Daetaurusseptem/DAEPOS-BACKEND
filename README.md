# DaePoint Backend

Backend for the POS system.

## Setup

1. Install dependencies: `npm install`
2. Configure `.env` (see `.env.example` if available, or use the one generated during setup)
3. Start MongoDB (locally or via Docker)
4. Run in development: `npm run start` (or `tsc -w` for development)

## Technologies

- Node.js
- TypeScript
- Express
- MongoDB (Mongoose)
- Firebase Admin (Storage)
- Stripe (Payments)
